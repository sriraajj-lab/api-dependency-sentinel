# Investor Thesis Source Ledger

## Evidence relevant to API Dependency Sentinel

| Source | Verified observation | Investor-theory implication |
|---|---|---|
| [GitHub Octoverse 2025](https://octoverse.github.com/) | GitHub reports that a new developer joins every second and frames AI, agents, and typed languages as major shifts in contemporary development. | The developer surface is growing while integration and agent complexity increases; Sentinel starts with TypeScript, a high-adoption integration environment. |
| [Stripe OpenAPI repository](https://github.com/stripe/openapi) | Stripe publishes GA OpenAPI specifications, recommends its `latest` directory for current API coverage, and retains a release changelog. | A provider offers machine-readable source material that can support auditable, commit-linked change detection instead of generic documentation monitoring. |
| [Stripe API upgrades](https://docs.stripe.com/upgrades) | Stripe states that major releases can include non-backward-compatible changes and may require code updates; API versions affect request, response, and webhook behavior. | Upstream API change is an operational engineering problem with concrete code and webhook implications. |
| [OpenAI API Changelog](https://developers.openai.com/api/docs/changelog) | OpenAI maintains a dated API changelog, including updates, deprecations, model changes, and named API surfaces. | OpenAI can be monitored as a distinct structured/unstructured source adapter; no market-size claim is inferred from this documentation. |

## Source-use constraints

These sources support the problem mechanism and the availability of provider evidence. They do **not** substantiate customer willingness to pay, market size, revenue, retention, or competitive advantage. Those points remain hypotheses until verified through design-partner conversations, paid pilots, and cohort retention data.
